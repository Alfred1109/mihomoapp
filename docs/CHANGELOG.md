# 📝 变更日志

## 🚀 v2.1.0 (2026-01-31) - DNS系统化优化

### ✨ 新功能
- **DNS三层架构**：实现default-nameserver、nameserver、fallback的完整DNS解析链
- **智能DNS分流**：通过nameserver-policy实现国内外DNS自动分流
- **HTTP/3优化**：启用prefer-h3加速DoH查询性能
- **广告屏蔽**：集成GEOSITE广告域名自动屏蔽

### 🔧 优化改进
- **路由规则优化**：重新设计分层路由，广告屏蔽优先级提升
- **fake-ip-filter扩展**：新增游戏、音乐、系统服务的排除列表
- **no-resolve优化**：为IP-CIDR规则添加no-resolve标记，减少DNS查询
- **测速URL改进**：使用www.gstatic.com/generate_204提高测速准确性

### 📊 性能提升
- DNS解析延迟：从2-7秒优化到50-200ms
- 国内网站访问：实现直连速度，避免错误代理
- 代理稳定性：达到与nyanpasu相当的性能水平

### 📚 文档完善
- 新增《DNS优化指南》详细技术文档
- 整合性能优化完整指南
- 系统化故障排查方案
